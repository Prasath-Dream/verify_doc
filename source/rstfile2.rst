.. START:section:1:0
How to Connect
==============

.. END:section:1:0

.. START:main_content:1:0
This section guides you through unpacking, assembling, and connecting the RB-RA8D1 kit. It's like building with Lego – simple steps to get everything working. We'll cover what's in the kit, how to put it together, and connecting extras. No tools needed except what's included!


.. END:main_content:1:0

**Kit Contents**
The following components are included in the kit:

1. RB-RA8D1 v1 board  
2. Micro USB device cable (type-A male to micro-B male)  
3. Micro USB host cable (type-A female to micro-B male)  
4. Ethernet patch cable  
5. Camera Expansion Board  
6. MIPI Graphics Expansion Board  
7. Nylon mounting stands (4x long, 2x short), nylon screws (6x)  

Unpack the box and lay out the board, cables, and manuals.  Inspect for damage (e.g., bent pins).  Place the board on a flat surface for setup.  Keep manuals handy. If items are missing, contact Renesas.

Nylon Screw Assembly
--------------------

Attach the graphics board securely.


.. START:note:1:0:4

.. note::

   **Requirements:** MIPI Graphics Board, nylon pillars (included), screwdriver (optional).
   

.. END:note:1:0:4

.. START:tip:1:0:5

.. tip::

   Align pillars with holes on RB-RA8D1.  
   Insert and tighten pillars.  
   Attach the graphics board to pillars.  
   Secure with screws.  
   Do not overtighten – this prevents wobble.

.. END:tip:1:0:5

Running the Quick Start Example Project on Console
--------------------------------------------------

Use the serial console for text-based control.


.. START:note:1:0:10

.. note::

   **Requirements:** Tera Term installed, COM port configured.
   

.. END:note:1:0:10

.. START:tip:1:0:11

.. tip::

   1. Connect USB debug cable.  
   2. Open Tera Term at 115200 baud.  
   3. Press keys for menus (e.g., 1 for kit info).  
   4. The console shows detailed system information.

.. END:tip:1:0:11

Overview of the Example Project
===============================

.. END:section:1:1

.. START:main_content:1:1
The example project is a pre-built program that shows off the board's features.  
It's like a demo app to get you started quickly.

.. END:main_content:1:1

This is the basic flow to start the project.


.. START:note:1:1:1

.. note::

   **Requirements:** Board assembled, USB connected, e2 studio installed.  
   

.. END:note:1:1:1

**Step-by-Step:**

1. Power on the board via USB.  
2. LEDs light up (blue blinks, green on, red off).  
3. Open e2 studio and import the project.  
4. Build and debug.
